# M20 — Enterprise GA & Lifecycle

M20 is the final major SDK architecture phase.

## GA contract

- package version: 1.0.0;
- Python support: 3.12, 3.13, 3.14;
- Platform API: 1.1;
- stable public imports;
- Apache-2.0 licensing;
- strict typing and >=90% test coverage;
- CodeQL and dependency auditing;
- SBOM and provenance attestations;
- trusted PyPI publishing;
- release artifact smoke testing;
- safe local diagnostics via `tinlance-agent-sdk`.

## Lifecycle policy

### Compatibility

Patch releases must remain backward compatible within Platform API 1.1.
Minor releases may add backward-compatible SDK surfaces. Breaking SDK changes
require a new major version.

### Platform compatibility

The SDK must not silently speak an unsupported Platform API version. A new
Platform API version requires an explicit compatibility declaration and
conformance tests.

### Deprecation

Deprecated public APIs must:

1. be documented in the changelog;
2. remain available for the documented migration window;
3. provide a replacement;
4. be removed only in a subsequent major release unless security requires
   earlier removal.

### Diagnostics

`tinlance-agent-sdk` performs local diagnostics only. It does not read
credentials, print secrets, or make network requests.

## Final architecture invariant

The SDK remains a developer surface and network contract layer. Platform
identity, authorization, policy, approvals, tools, secrets, sandboxing,
execution, evidence authority and audit remain outside the SDK.

M20 completion requires a final forensic review of source, tests, workflows,
documentation, package metadata, contract manifests and public exports, followed
by green CI and security workflows.
