# M16 — Enterprise Observability

M16 adds an optional telemetry seam without making OpenTelemetry or another
telemetry runtime a dependency of the SDK.

The SDK emits only:

- operation name;
- request ID;
- HTTP status;
- elapsed time;
- error type.

It does not emit bearer credentials, tenant/subject assertions, request
payloads, response payloads, tool inputs, evidence content, or authorization
material through the telemetry interface.

The hook is failure-isolated: telemetry callback failures cannot change the
request outcome.

Applications may adapt `TelemetrySink` to OpenTelemetry. This follows
OpenTelemetry's library guidance to keep instrumentation optional and
application-owned. The SDK continues to propagate W3C trace context separately.
