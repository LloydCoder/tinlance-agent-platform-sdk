# M21.1 — Platform Conformance

**Status:** Complete when the M21.1 conformance gate is green on the default branch.

## Objective

Prove that SDK 1.0.0 interoperates with the currently published Tinlance Agent Platform API 1.1 boundary without inventing remote operations or moving authority into the SDK.

## Certified public operation set

The suite exercises every operation currently published by the SDK contract:

- health
- principal.get
- agents.list
- capabilities.list
- runs.create
- runs.cancel
- approvals.request
- approvals.decide
- tools.execute
- executions.get
- runs.events
- runs.evidence

The expected response-status map is reconciled against docs/contracts/sdk-contract-manifest.json.

## R10 certification boundary

M21.1 verifies the client-side wire contract for governed-execution.v1, including capability/tool versions, requested execution limits, risk metadata, sandbox/evidence requirements, request correlation and idempotency headers. The Platform remains authoritative for identity binding, authorization, policy, approval, sandboxing, evidence and execution.

## Security invariants covered

- authenticated requests use the documented versioned gateway;
- consequential operations carry a stable request/idempotency identity;
- read operations do not receive an idempotency key;
- the SDK sends the exact R10 contract identifier rather than selecting a local protocol;
- no test grants authority from client assertions;
- no unsupported resource, streaming, pagination or webhook endpoint is introduced.

## Completion gate

M21.1 is complete only when the dedicated conformance tests, normal CI, security workflow and package smoke gate are green. The test server is deterministic and local; it proves SDK wire behavior, while server-side R10 certification remains authoritative in the Platform repository.

## Source authority

The authoritative server-side boundary is:

- Tinlance Agent Platform docs/R10-GOVERNED-EXECUTION.md
- Tinlance Agent Platform docs/R10-CERTIFICATION.md
- SDK docs/contracts/SDK-V1.0-CONTRACT.md
- SDK docs/contracts/sdk-contract-manifest.json

External security alignment includes NIST's 2026 work on software-agent identity and authorization, OWASP's 2026 Agentic Applications Top 10, and OpenTelemetry semantic conventions. These inform the security posture; executable Platform contracts remain the source of truth.
