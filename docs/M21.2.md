# M21.2 — Agent Developer Surface

**Status:** Complete when the M21.2 implementation, tests, documentation and CI gates are green.

## Objective

Provide a typed, declarative Agent Developer Surface for composing agents without turning the SDK into an authority engine or second runtime.

## Surface

AgentSpec now describes:

- identity-facing display metadata: name, version and description;
- declarative capabilities;
- instructions and reference metadata;
- tool descriptors;
- model/provider metadata;
- guardrail metadata;
- local lifecycle metadata;
- safe observability metadata;
- arbitrary non-sensitive developer metadata.

The SDK serializes this information locally through AgentSpec.as_payload(). The current Platform API 1.1 operation gateway does not expose an agent-definition registration operation, so the SDK does not invent one.

## Authority boundary

The following remain Platform-owned:

- authenticated identity and tenant binding;
- authorization and policy;
- approval authority;
- secret ownership and credential resolution;
- sandboxing;
- tool execution;
- evidence validity;
- execution lifecycle authority.

ModelSpec identifies a provider/model; it does not carry credentials or authorize provider use. GuardrailSpec describes developer intent; it does not replace Platform policy. LifecycleSpec describes local composition behavior; it does not create remote state-transition authority. ObservabilitySpec never implies payload capture.

## Completion gate

M21.2 is complete only when the public developer contracts, exports, tests, documentation, package smoke, Python matrix, security workflow and CodeQL are green.
