# M21.5 — Observability and Evaluation Surface

**Status:** Complete when observability/evaluation tests and all CI/security gates are green.

## Objective

Expose safe agent-level observability semantics and typed evaluation references without turning the SDK into an observability backend or evaluation authority.

## Agent telemetry vocabulary

The developer surface can classify spans/events around:

- agent.run
- agent.step
- agent.tool
- agent.approval
- agent.handoff
- agent.evidence
- agent.error

The existing telemetry contract remains allow-listed and payload-free by default. Prompts, raw tool arguments/results, credentials, secrets and sensitive evidence are not exported through safe_attributes.

## Evaluation surface

The SDK now provides:

- EvaluationCase — versioned case metadata;
- EvaluationAssertion — assertion state and safe reason codes;
- EvaluationResult — pass/fail/unknown/partial plus evidence/trace references.

The SDK does not calculate benchmark scores, adjudicate evidence, or replace FAS/FAS-Bench. Evaluation engines remain domain-owned.

## OpenTelemetry alignment

The surface is compatible with OpenTelemetry-style agent spans while keeping authority-neutral attributes. A production adapter can translate these references into an organization's telemetry system without granting the telemetry layer execution authority.

## Completion gate

M21.5 is complete only when the new types, tests, documentation, package smoke, Python matrix and CodeQL are green.
