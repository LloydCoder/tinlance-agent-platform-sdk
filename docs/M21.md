# M21 — Final Enterprise Program

M21 is the final planned engineering program for the external Tinlance Agent Platform SDK.

| Stage | Scope | Completion rule |
| --- | --- | --- |
| M21.1 | Platform API 1.1 and R10 wire conformance | all published operations and client-side R10 invariants tested |
| M21.2 | Agent Developer Surface | declarative agent contracts without authority duplication |
| M21.3 | Durable lifecycle readiness | unsupported run-get/wait/resume surfaces remain fail-closed |
| M21.4 | MCP/tooling integration metadata | transport/auth/tool descriptors without an MCP runtime |
| M21.5 | Observability/evaluation references | payload-minimized telemetry and typed evaluation references |
| M21.6 | Security/supply-chain certification | executable control matrix plus security gates |
| M21.7 | Enterprise release/certification | version/contract/release reconciliation and artifact gates |

## Final architecture boundary

The SDK is the external developer surface over the Tinlance Agent Platform. It may define typed contracts, local composition helpers, metadata, references and transport configuration.

The Platform remains authoritative for:

- identity and tenant binding;
- authorization and policy;
- approvals;
- credentials and secrets;
- sandboxing;
- tool execution;
- evidence validity;
- governed lifecycle transitions;
- audit authority.

The SDK must never become a second Agent Platform.

## Contract-evolution rule

A future remote operation requires a versioned Platform contract, executable server-side conformance tests, an SDK compatibility entry and client-side regression coverage. Missing server contracts are represented as readiness gates rather than invented APIs.

## Final state

After M21.7 and the forensic reconciliation pass, the repository moves to controlled maintenance and compatibility releases. Future work should be driven by authoritative Platform contract changes, not by adding speculative runtime authority to this SDK.
