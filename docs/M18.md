# M18 — Multi-language Ecosystem Contract

The SDK repository now has a canonical machine-readable contract manifest at
`docs/contracts/sdk-contract-manifest.json`.

It defines:

- Platform API version;
- wire method/path;
- success status semantics;
- public operations;
- deferred operations;
- language-generation rules;
- authority boundary.

Python remains the reference SDK. TypeScript and Go surfaces, when introduced,
must derive operation names, status semantics, headers and deferred capabilities
from this manifest and the authoritative Platform contract.

No language-specific SDK may introduce an operation absent from the canonical
manifest or grant authority that belongs to the Platform.

This phase deliberately establishes the generation boundary before publishing
parallel language implementations; that prevents protocol divergence.
