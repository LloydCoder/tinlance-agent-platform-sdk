# M19 — Conformance & Supply-Chain Engineering

M19 establishes an inspectable compatibility and release-security contract.

The repository verifies:

- Python 3.12/3.13/3.14;
- Platform API 1.1 compatibility;
- source-level tests and strict typing;
- wheel/sdist build validity;
- dependency audit;
- SBOM generation;
- CodeQL analysis;
- release provenance attestation;
- trusted PyPI publishing;
- security regression invariants.

The compatibility matrix is machine-readable at
`docs/contracts/compatibility-matrix.json`.

A release must be treated as an artifact: CI must build distributions and verify
that the resulting package metadata and import surface are valid before
publication.
