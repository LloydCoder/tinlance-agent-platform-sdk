# Support

Use the channel that matches the problem.

| Need | Where to go |
| --- | --- |
| SDK usage or configuration | Open a GitHub issue with the relevant version, Python version, and a minimal reproduction |
| Bug report | Use the **Bug Report** issue form |
| Feature request | Use the **Feature Request** issue form |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not use a public issue |
| Code of Conduct concern | Email **hello@tinlance.com** |
| Commercial or platform questions | Contact **hello@tinlance.com** |

## Before opening an issue

1. Read [README.md](README.md).
2. Check [docs/README.md](docs/README.md).
3. Search existing issues.
4. Reproduce the problem with the smallest possible example.
5. Remove credentials, tokens, private keys, and customer data from logs.

Support is provided on a best-effort basis. Security reports follow the response targets documented in [SECURITY.md](SECURITY.md).
